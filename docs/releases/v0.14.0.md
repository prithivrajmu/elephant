# Elephant 0.14.0

This release adds read-only dreaming evaluation through `dream-eval`. Retrieval probes compare recall before and after a proposed correction. The optional local scheduler `--probe-file` gate blocks proposals that fail those checks. Use `--review-order risk` to prioritize negative-feedback memories within each bounded page.

Fragment probes are retrieval contracts. They do not certify factual accuracy or establish improved model quality. Automatic reviews remain opt-in. Existing identity, scope, pagination and byte limits remain in place.

The repository also includes historical-task and history-dependent benchmark tooling, source-bound fixture controls, and an updated Pillow dependency for optional experiments. These tools do not change production retrieval defaults. No new live-model efficacy result is claimed.

See the [dreaming guide](https://github.com/prithivrajmu/elephant/blob/main/docs/dreaming.md) for configuration and limits.

## Upgrade

```sh
npx --yes elephant-memory@0.14.0
```

Restart running agents and Memory Palace after upgrading. Run `elephant init` in each project to refresh hooks and guidance. Existing scheduler settings are preserved.

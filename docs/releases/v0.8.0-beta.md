# Elephant 0.8.0-beta

First public beta for a closed circle of testers. This is a prerelease; expect
rough edges and report them through GitHub issues.

## Highlights

- Public repository, correct Go module path (`github.com/prithivrajmu/elephant`).
- Third-party license notices ship inside every release archive.
- The Memory Palace dashboard no longer serves its API token on `GET /`; open the
  `#token=` link that `elephant palace` prints.
- Cloud sync keeps a local retirement authoritative, and uploads opaque project IDs
  instead of absolute local paths.
- Memories that contain common credential formats are rejected before storage.
- Automatic reviews run only for tasks with a file edit or failed tool call.
- Release checks accept the `beta` channel; pilot and beta installations share one
  prerelease lane. Installations older than this release do not recognize `beta`
  tags and must be updated manually from the Releases page.

## Known limitations

- Packages are unsigned.
- Hooks are supported on macOS and Linux only.
- Secret screening is heuristic and not a guarantee.
- Local tenant and user labels are not authentication.

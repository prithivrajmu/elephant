Writing target

Use ASD-STE100 as the writing guide. The target is a setting. It is not a compliance score.

80–99%: show local warnings. 100%: reject new summaries that fail local checks. These checks cover sentence length, selected complex phrases and selected contractions. They do not validate the full standard. Evidence, code and old Memories stay unchanged.

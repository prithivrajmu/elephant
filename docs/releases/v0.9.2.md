# Elephant 0.9.2

Fixes lost lessons, shows hook errors, and stops the dashboard from presenting an
estimate as a saving. Releases now publish from a version tag.

## Capture

- A review that a new prompt interrupts saves its lessons under its own task.
  Before, `remember` and `task-status` failed with "task changed before capture"
  and the lesson was lost.
- A stale `task-status` command prints a read-only line instead of failing. The new
  states are `superseded` and `already_reported`.
- Unreviewed edits and failed tool calls carry to the next task when the host skips
  the finish hook, for example after a user interrupt.
- Refusals from `remember` and `task-status` say what happened and what to do.

## Errors and honest numbers

- When a hook fails, Claude Code shows the error text. Before, it showed only
  "See hook stderr for details".
- `doctor` notes agent guidance that is older than the installed version and names
  the command that updates it. This is a note, not a failure.
- The dashboard leads with "Recall context added", the tokens recall put in front of
  the agent. The all-memories baseline stays as a comparison. It is not a saving
  against using no memory, and the `stats` output says so.
- Helpful feedback shows as "2 of 2" with a note that the agent reports it, instead
  of "100%". `stats` counts only active memories.

## Security

Release builds use Go 1.27.2. It fixes nine standard-library vulnerabilities that
`govulncheck` reports against Go 1.27.1, in `net/http`, `crypto/tls` and
`net/textproto`. Cloud sync and the dashboard use these packages. Upgrade to get
the rebuilt binaries.

## Also in this release

- Local recall phase traces, p50/p75/p95 Memory Palace metrics and performance
  ratchets, merged in PR #33 after 0.9.1.
- Releases publish when a `vX.Y.Z` tag is pushed, not on every merge to `main`.
  See [Releasing](../releasing.md).

## Upgrade

```sh
npx --yes elephant-memory@0.9.2
elephant version
elephant init
```

Run `elephant init` again in each project. It updates the agent guidance, and
`doctor` reports projects that still have the old text. Restart running agents and
Memory Palace after installation. No store migration is required. Packages remain
unsigned, and Windows uses MCP without automatic hooks.

# Elephant 0.9.0-beta

Faster local recall, more reliable setup, and the updated Memory Palace.

## Recall and memory storage

- Cache lesson word sets and update diversity comparisons once per selected result.
- Remove entries that cannot fit the remaining context budget before further ranking.
- Index alternative advice by subject and lesson, retaining total counts and up to
  five sorted alternative IDs. This removes quadratic usage-baseline comparisons.
- Check record retries against matching evidence in the same owner's scope and
  project. Label order, case, and duplicate values no longer create duplicate memories.
- Preserve original evidence, separate sources, applicability conditions, and origins.

On an Apple M4, the synthetic 1,000-memory retrieval benchmark fell from 25.6 ms
to 8.4 ms. A SQLite stress case where every memory shares a subject fell from
1,801 ms to 34.2 ms. These are local benchmark results, not host/model latency
or productivity claims. See [validation](../validation.md) for methodology.

## Setup

```sh
elephant setup --auto --agent codex
```

Use `claude` or `both` for other supported adapters. `init` remains available.
Both commands check store access before installing hooks and report local health
checks afterward. Reruns preserve the existing agent choice unless overridden.

`doctor` now detects missing or non-executable binaries, missing hooks, and
missing guidance. An explicitly different store or identity is diagnosed separately
from installed project hooks. Restart the agent and approve its hooks normally.

The MCP file wizard uses absolute launch paths, follows changes to the project
folder, and safely fills in missing files on identical reruns. Existing edits are
preserved. Failed file generation does not change the store's writing policy.

## Memory Palace

This release includes the interactive brain atlas from PR #30, with connected
memory nodes, animated activity, and a detail drawer. The Palace validation
script is now part of the release workflow.

## Upgrade and limits

Install the matching archive from this release and rerun `elephant init` in
projects that use automatic hooks. Restart agents and dashboard processes so
they load the new binary. Existing stores need no new schema migration.

This remains an unsigned beta. Automatic hooks support macOS and Linux;
Windows uses MCP setup. Recall remains lexical and still scans eligible current
memories for corpus statistics. Native host approval and model-driven lesson
extraction are separate from the automated protocol tests.

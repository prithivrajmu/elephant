# Elephant 0.7.0-pilot

This prerelease improves local recall and update diagnostics, and adds an optional
Cloudflare MCP service with explicit sync, reviewed sharing and evidence reads.
Local use remains the default. Publishing this release does not deploy a hosted
service or upload existing Memories.

## Highlights

- **Scoped SQL recall:** select applicable identity/context candidates through
  SQLite indexes before decoding. Preserve applicability filters, the eligible
  BM25 corpus and context budgets. A synthetic 10,000-row selection benchmark
  improved from 87.9 ms to 4.8 ms; this is not complete recall latency. Further
  lexical narrowing remains benchmark-only.
- **Clear update checks:** show Checking progress and actionable messages for
  release access, credentials, rate limits, connectivity and timeouts. Each
  manual check makes a fresh request; dashboard polling reads the cache. Last
  attempt is distinguished from a successful result. No automatic installation.
- **Backend contracts:** separate service operations from concrete local storage,
  with versioned hosted operations and shared Go/TypeScript behavior fixtures.
- **Optional Cloudflare hosting:** authenticated MCP over the Agents SDK,
  user-scoped SQLite Durable Objects, bounded retrieval and transactional receipts
  for retries. All six private memory tools are available remotely.
- **Explicit cloud sync:** selected scopes, persistent offline outbox, stable
  retry IDs, revision conflicts and retirement propagation. No automatic upload.
- **Reviewed team sharing:** immutable proposals, separate authorized reviewers,
  provenance, withdrawal and local approval before imported advice becomes active.
- **External MCP evidence:** an explicit read_evidence tool for allowlisted,
  read-only tools, with bounded output and provenance. Evidence is untrusted and
  is not automatically recorded or approved as a lesson.

## Install or upgrade

Download the ZIP for your OS and architecture from this release. Six archives
cover macOS, Linux and Windows on amd64/arm64. SHA256SUMS accompanies the archives;
each archive also contains its own checksum-verifying installer and documentation.
Repository access is required while Elephant is private. Packages are unsigned.

Before upgrading, stop running Elephant processes and create a verified backup.
From the extracted archive on macOS/Linux:

```sh
ELEPHANT_REPLACE=1 sh ./install.sh
export PATH="$HOME/.local/bin:$PATH"
elephant version
elephant selftest
```

For a new installation, use `sh ./install.sh` without ELEPHANT_REPLACE. On Windows,
use `./install.ps1 -Replace` for an upgrade or `./install.ps1` for a new install.
Restart your dashboard and agent processes to use the new binary. Existing local
MCP tool names and hook workflow remain compatible. Source builds require Go 1.26+.

Update checks against the private repository need ELEPHANT_GITHUB_TOKEN in the
Elephant process environment, with authorized repository access. A GitHub browser
login alone does not authenticate the binary. Never embed or commit a shared token.

## Storage and hosted setup

Existing 0.6 SQLite stores remain local; no bulk migration is required for recall.
Cloud sync adds bookkeeping tables when explicitly used. Users upgrading older
JSONL stores retain the 0.6 migration behavior and original `.jsonl-backup`.
Preserve a verified backup before upgrading or downgrading; do not assume older
binaries understand newly synchronized state.

Portable archives contain the local binary and guides. Hosted Worker source is
available in the repository at this tag under `cloudflare/`; deploying it requires
Cloudflare configuration and an existing token issuer. Production interactive
login is not supplied by this release. See the bundled `docs/cloudflare.md`,
`docs/cloud-sync.md` and `docs/mcp-evidence.md`.

## Validation and pilot limits

Publication is gated by native Linux/macOS/Windows race tests, vet, selftest,
external MCP/storage checks, generated-hook acceptance on macOS/Linux, six-archive
package checks, and Cloudflare TypeScript checks, 30 Workers-runtime tests and a
Wrangler dry run. The publisher downloads uploaded assets and compares them to
its build before making the release visible.

Automated hook tests simulate lesson extraction; real model-driven capture and
retrieval quality still need pilot evidence. ARM archives are cross-compiled;
that alone does not certify native ARM installers. The SDK evidence lifecycle
integration is experimental and pinned. Hosted ranking uses bounded candidates,
so numerical parity with full local ranking is not claimed.

Free-tier suitability requires deployed CPU/quota measurements. Receipt/storage
caps are pilot safeguards, and long-running retention remains future work.
Retirement is not physical erasure. Shared snapshots require their own withdrawal
separately from retiring the original private lesson. No hosted deployment or
production load certification accompanies this release.

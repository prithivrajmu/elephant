# Elephant 0.15.3

This patch changes the macOS menu-bar **Updates** menu. Memory behavior is unchanged.

## Updates

- One **Updates** menu installs into every Elephant binary in use: connected servers, the menu-bar companion, and `elephant` on `PATH`.
- The same file counts once. npm launcher copies under `~/.elephant/bin/<tag>` are listed and not replaced.
- Each binary is judged on its own version and release lane, so one confirmation can install different releases.
- Checks are disabled for the whole menu when the companion, any connected session, or any connected store disables them. The menu does not write that decision back.
- `elephant update` and Memory Palace stay per store. A session cannot supply a GitHub token.
- The top row lists every running version. **Restart Needed** appears when a running process differs from the file on disk.
- Nothing restarts automatically. Replacing the menu-bar binary requires **Hide Menu Bar**.

## Upgrade

```sh
npx --yes elephant-memory@0.15.3
```

Existing stores, hooks, and scheduler settings are unchanged. Running processes keep the previous executable until restarted.

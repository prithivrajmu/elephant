# Elephant 0.15.0

This release adds a native macOS menu-bar companion and a shared Elephant logo for dialogs and the README. Linux and Windows retain their CLI/MCP workflows.

## Native controls

- Sessions group connections by project and show client names, short instance IDs, optional conversation metadata, and temporary nicknames. Open Memory Palace for the exact selected context.
- Updates show cached availability and support explicit checks and confirmed, checksum-verified installation. Installation never restarts active servers. Releases remain unsigned; checksums verify agreement with published assets, not publisher identity.
- Dreaming shows schedule/reviewer status and real results. Configure bounded reviews, request Dream Now, pause/resume scheduling, or cancel a review. Provider use requires consent. Foreground, daily-budget, concurrency, source, revision, and commit guards remain in effect.
- Health checks inspect local storage, hooks, and configured reviewer availability. Clipboard diagnostics exclude paths, identities, names, credentials, and memory text.
- Project controls reveal the project and pause/resume or explicitly repair automatic hooks. Explicit MCP calls continue while hooks are paused.

MCP observation retains only client identity and tool name/time/outcome metadata. A connection is not proof of an active chat or task. No live-model quality improvement is claimed.

## Upgrade

```sh
npx --yes elephant-memory@0.15.0
```

Hide an older menu-bar companion, then restart running Elephant MCP servers with the new binary. Running processes retain their previous executable image. Run `elephant init` where hook guidance needs refreshing; existing scheduler settings are preserved.

Set `ELEPHANT_MENU_BAR=0` to disable the icon for a process. Menu-bar use requires a logged-in macOS desktop and uses built-in system tools, not Swift or Xcode.

See the [menu-bar guide](../dashboard.md#macos-menu-bar), [dreaming guide](../dreaming.md#macos-menu-controls), and [update guide](../updates.md#macos-menu-bar-installation).

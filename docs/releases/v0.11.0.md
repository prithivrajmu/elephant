# Elephant 0.11.0

Recall injects fewer unrelated lessons, and the task status line no longer
reports `capture failed` when Elephant refuses a lesson on purpose.

## Recall relevance

- Recall scores lessons with TF-IDF cosine, the measure the near-duplicate check
  already uses, and admits only lessons at or above 0.074. BM25 and the
  generic-term gate are gone. A 0.4 IDF floor keeps words that every lesson
  shares from weighing zero.
- Simple plurals now match, such as `models` and `model`.
- On 78 labelled tasks over a real 167-lesson store, recall injected 161 lessons
  instead of 265. 52 were useful instead of 48, and 65 were unhelpful instead of
  158. nDCG@3 rose from 0.44 to 0.49. 6 of 20 off-topic tasks now get nothing.
- The relevance fixture's unrelated injections fell from 8 to 4 with no needed
  lesson lost.
- Terms are summed in sorted order, so recall results are reproducible.
- The dashboard's tokens baseline counts only memories that recall can admit.
- Local recall only. The hosted Cloudflare worker is unchanged.

## Task status after a refused lesson

Before, every error from `remember` or `record` was journalled as
`capture_failed`. A near-duplicate refusal, followed by a save, produced
`saved 1 lesson · capture failed` although nothing failed.

- A refusal (invalid fields, sensitive content, the writing check or a
  near-duplicate) is journalled as `capture_rejected` with a reason code. The
  journal never stores the error text.
- A save after refusals reads `saved 1 lesson`.
- Refusals with no save read `saved 0 lessons · 1 attempt rejected`.
- A store or input error still reads `capture failed`, also after a later save,
  because that save can be a different lesson.
- `task-status --json` adds a `rejected` count and a `rejected` state.

Journal rows written by older versions are unchanged.

## Upgrade

```sh
npx --yes elephant-memory@0.11.0
elephant version
```

No store migration is required. Restart running agents and Memory Palace after
installation. Packages remain unsigned, and Windows uses MCP without automatic
hooks.

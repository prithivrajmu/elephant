# Elephant 0.6.0-pilot

This prerelease adds durable SQLite storage and clearer task updates for a local developer pilot.

## Highlights

- SQLite WAL with FULL synchronization, a bounded writer timeout, and transactional memory state, audit events, deduplication keys and save receipts.
- Automatic JSONL migration at the existing store path, preserving IDs, evidence, scopes, approvals, retirement and feedback. The original is retained as `<store>.jsonl-backup`.
- `elephant backup` and `elephant restore` for consistent snapshots and verified recovery to a new path.
- Factual end-of-task status, for example `Elephant: recalled 2 memories · saved 1 lesson.` Incomplete review, capture failure, pause and no-lesson outcomes are distinct.
- Cached release notifications with check, dismiss and disable controls. Updates are never installed automatically.
- Six portable macOS/Linux/Windows archives with SHA-256 checksums and included documentation.
- A focused README and named guides under `docs/`.
- Correct Windows drive-letter SQLite URIs and fail-fast native CI checks.

## Install

Download the ZIP matching your OS and CPU from this release and extract it. Apple Silicon Macs use `darwin-arm64`; Intel Macs use `darwin-amd64`; most PCs use `amd64`.

macOS/Linux, from the extracted folder:

```sh
sh ./install.sh
export PATH="$HOME/.local/bin:$PATH"
elephant selftest
cd /path/to/project
elephant init
```

Restart Codex/Claude Code and approve the installed hooks normally. On Windows, run `install.ps1`, add `%LOCALAPPDATA%\Elephant\bin` to PATH, then use `elephant setup --wizard` for MCP integration.

The repository is currently private, so downloads require repository access. Packages are unsigned. The installer verifies checksums; it does not alter host trust or script policy. Go is only needed for source builds (Go 1.25+).

## Upgrade and compatibility

Use `ELEPHANT_REPLACE=1 sh ./install.sh` on macOS/Linux or `./install.ps1 -Replace` in PowerShell to replace an existing binary. Stop older Elephant processes before migrating shared history.

New stores default to `~/.elephant/memories.sqlite`. Existing modern/legacy JSONL paths migrate on first access. Sidecar settings and installed hook paths remain unchanged. Older binaries cannot read a migrated store. The original migration backup does not contain later writes.

CLI/MCP field names and the six MCP tool names remain compatible. Automatic hooks support macOS/Linux Codex and Claude Code; Windows and other clients use MCP/CLI integration.

## Validation and limits

The release workflow gates publication on native Linux/macOS/Windows race tests, vet, binary selftest, external MCP and storage acceptance, macOS/Linux generated-hook acceptance, and six-archive checksum/document checks.

A fixed-one-memory benchmark with 100,000 historical events measured a median state read of 1.34 ms with SQLite versus 216.30 ms for JSONL decoding. This is a storage microbenchmark, not complete task latency. Recall still scans current memories, alternative-advice work can be quadratic, usage history is unbounded, and retention remains future work.

Real model-driven host acceptance and physical power-loss simulation are not claimed. Local identity labels are trusted configuration rather than enterprise authentication. Memories and backups are not encrypted by Elephant.

Migration interrupted before replacement preserves the original, but may leave a stale migration lock requiring explicit recovery after processes stop. Normal SQLite write crashes recover automatically. See the bundled `docs/storage.md` and `docs/validation.md` for details.

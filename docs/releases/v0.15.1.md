# Elephant 0.15.1

This patch updates Elephant branding without changing memory behavior or the macOS menu-bar icon.

## Branding

- Use the supplied Elephant artwork in Memory Palace and its browser icon.
- Show light/dark artwork in the README and include logo images in release archives.
- Use the new artwork in native macOS dialogs. The existing monochrome menu-bar silhouette and attention indicator are unchanged.
- Include dialog artwork in the native app bundle and its cache identity so upgraded companions use the new logo.

## Upgrade

```sh
npx --yes elephant-memory@0.15.1
```

Hide an older menu-bar companion, then restart running Elephant MCP servers with the new binary to see the updated dialog artwork. Running processes retain their previous executable image. Existing stores, hooks, and scheduler settings are unchanged.

See the [menu-bar guide](../dashboard.md#macos-menu-bar) and [update guide](../updates.md#macos-menu-bar-installation).

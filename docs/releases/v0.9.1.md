# Elephant 0.9.1

Fixes stale release status from the `elephant update` command.

## Update checks

- Plain `elephant update` now forces a fresh release lookup. Previously it could
  report no newer release from a cache written before that release was published.
- Explicit checks always show the available version and release link, even if
  a background hook has already announced it.
- `elephant update --json` remains a cached status read. Add `--check` to refresh.
- Dismiss and enable/disable commands stay offline unless `--check` is supplied.
  Disabled checks remain disabled, and background checks keep their daily cache.

## Upgrade

```sh
npx --yes elephant-memory@0.9.1
elephant version
elephant update
```

The npm launcher verifies the release checksum and installs the binary.
The `update` command checks availability; it does not install a binary.
On older releases, use `elephant update --check` to force a fresh lookup.
Restart running agents and Memory Palace after installation.

Version 0.9.1 has no prerelease suffix and publishes under npm's `latest` tag.
Existing beta installations can discover this release. The project remains
pre-1.0 with the beta limitations described in the README. No store migration
is required. Packages remain unsigned, and Windows uses MCP without automatic hooks.

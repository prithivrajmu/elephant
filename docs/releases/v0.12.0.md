# Elephant 0.12.0

Elephant shows a short status when an automatic hook recalls lessons or starts a
review. The prompt status includes the count even when there are zero matches.

## Offline evaluation

The repository includes a memory-tax evaluation with synthetic and sanitized
fixtures, raw BM25 and optional dense retrieval, bounded follow-up questions,
and diagnostics for comparing retrieval methods. The experiments run separately
from production recall.

## Upgrade

```sh
npx --yes elephant-memory@0.12.0
elephant version
```

Restart running agents and Memory Palace after upgrading. No store migration is
required.

# Elephant 0.15.2

This artwork-only patch removes generator marks from the full light and dark Elephant logo images. It does not change memory behavior.

## Artwork

- Crop exactly 100 pixels from all four edges of both full logo images, without resampling.
- The full light image is now 1000 × 470 pixels. The full dark image is now 871 × 600 pixels.
- The other five logo assets, including icon variants, are unchanged.

## Upgrade

```sh
npx --yes elephant-memory@0.15.2
```

Existing stores, hooks, scheduler settings, and memory behavior are unchanged.
